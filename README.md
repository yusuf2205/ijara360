# Ijara360

Система управления арендным домом для студентов. Основная единица учёта — **спальное место**: дом → комната → место → период проживания.

**Текущий результат: проектирование M1 — Foundation, версия 0.1 от 25 сентября 2026.** Это проектная база для проверки и последующей реализации, а не работающее приложение. Backend, мобильный клиент и рабочие миграции пока не созданы. M2 не начат.

## Хранение

Основной сервер: **UGREEN DXP4800 Plus, 192.168.1.105**. Корневой каталог проекта: `/volume1/docker/ijara360`.

- GitHub: https://github.com/yusuf2205/ijara360
- Gitea: https://mygithub.uz/joseph/ijara360
- NAS: версионированные копии исходников и Git bundle; приложение и рабочие данные размещаются здесь по мере реализации.

Код и документация хранятся в обоих Git-репозиториях. База данных, видео, секреты и резервные копии рабочих данных хранятся отдельно от Git.

В SQL отмечены ограничения, которые требуют транзакционной реализации. Его нельзя считать готовой production-миграцией или доказательством работы API.

## Последовательность

1. Зафиксировать проект M1 и реализовать Auth, Users/RBAC, Property, Rooms, Beds, Audit.
2. Пройти критерии приёмки M1 и зафиксировать результат этапа.
3. Перейти к M2 — Residents/Occupancies только по отдельному решению владельца проекта.
4. Далее последовательно M3 Finance, M4 Owner Mobile, M5 Cameras, M6 AI, M7 Analytics.

Камеры, AI, распознавание лиц, гости, платежи и заселение не реализуются в рамках текущего проектирования.
