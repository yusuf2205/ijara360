UI проверяет OWNER/ADMIN и M2, создание начисления, частичную/полную оплату, ограничение/восстановление допуска, grace, фильтры, аванс, расшифровку его распределения. Persistence использует `scripts/test-m3-persistence.cjs before/after` и явный restart четырёх **тестовых** контейнеров. Сравниваются все receipts, charges, allocations, оставшийся аванс, флаги и итоговые суммы; исключены только asOf/financeCheckedAt. Приватное состояние тестового сеанса хранится в игнорируемом `.local/m3-persistence.json`.

## Границы поставки

- Принято правило допуска после льготного периода; просрочка видна уже после dueDate. Без льготного периода блокировка начинается на следующий день после dueDate.

- Финансовые записи сохраняются неизменяемыми. Сторно/возвраты/аннулирование не реализованы и требуют отдельного сценария; проверяйте суммы перед подтверждением.
- M8/M9: подготовлен финансовый API, физические камеры и замки не подключены.
- Ежедневный NAS cron backup и off-NAS копия остаются отдельными инфраструктурными задачами. Предрелизные backup/restore выполняются автоматически каждым deployment.
